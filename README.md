# AI API Pricing Index — November 2026

Dated list prices for frontier, mid-tier and open-weight AI APIs, with vendor source links and a CSV.

## Files

- `ai-api-pricing-2026.csv` — one row per model or plan, with provider, input, cached input, output, context, pricing model, checked date and source URL.
- `README.md` — method, citation and corrections.

## What changed this month

- OpenAI priced GPT-6.2 Astra at $8 input and $40 output per million tokens, 20% below GPT-6 Astra, with cached input at $0.40.
- Google placed Gemini 4 Neon at $3 / $15 and kept Gemini 4 Carbon at an introductory $2 / $10 that ends on 30 November 2026.
- Anthropic listed Claude Fable 5.2 at $8 / $40.
- Groq, Cerebras and SambaNova continued to compete on open-weight tokens well below frontier output prices.

## Method

Prices are standard list prices in USD per million tokens, taken from the vendor's own pricing or launch page on the date shown. Cached-input rates are included where the vendor publishes them. Batch, flex, priority and negotiated rates are excluded unless a row says otherwise. Context windows are shown where the vendor published them; “not stated in launch post” or “n/a” means the page did not state a figure, not that the model has no limit. Taxes, minimum commitments and regional uplifts are excluded.

The CSV keeps the source URL for every row. If a vendor changes a price, open an issue with the vendor URL and the date.
